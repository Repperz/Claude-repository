# Sailing Games

Two single-file HTML sailing games. Open `index.html`, or either game directly, in a web browser.

- **[Belladonna's Journey](sailing-games/belladonnas-journey.html)**: sail the yacht Belladonna anywhere in the world. The wind follows the planet's real belts (doldrums, trade winds, westerlies, Roaring Forties). She carries up to 50 days of food and water, refilled at any of 29 ports.
- **[Westward Passage](sailing-games/westward-passage.html)**: cross the North Atlantic from Falmouth to the US east coast, using the NE trade winds around the Azores High.

## How to play

- Steer with ← / → (or A / D) and trim the sail with ↑ to sheet in and ↓ to ease out. On-screen buttons work on phones.
- The boat can't sail within 35° of the wind, and the sail must be set roughly right for the wind angle (keep the marker in the green band).
- Space pauses. The time buttons speed the voyage up.

## Notes

- Each game is one self-contained file. Coastlines in Belladonna's Journey are simplified from [Natural Earth](https://www.naturalearthdata.com/) 1:50m land data (public domain).
- Phone previews of an HTML attachment (WhatsApp, Mail, Files) don't run scripts, so share a web link (for example GitHub Pages) rather than the file.
